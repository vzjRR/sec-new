# Agent charters

The `/TSU` + `/TSG` model: 18 specialist roles, each with a defined scope, the verified
surface it may rely on, its current blockers, and its definition of done.

These are **working charters, not job descriptions.** Each one names the surface that
exists (per `docs/ENVIRONMENT_AUDIT.md` §7) and the experiments blocking it, so a role
cannot quietly drift into inventing capability the platform does not have.
